# OutboundLogStreamEntryType

Kind of entry in an `ndjson` stream of outbound logs:  - `log`: An outbound log entry. - `error`: An error that ended the stream. - `cursor`: The cursor for the next page. Always the last entry. 

## Enum

* `LOG` (value: `'log'`)

* `ERROR` (value: `'error'`)

* `CURSOR` (value: `'cursor'`)
